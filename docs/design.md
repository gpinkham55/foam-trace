# Foam Tracer design

## Goal

Upload a backlit phone photo of hand tools on a 5 mm grid and download a millimetre SVG for waterjet-cutting a foam insert. Static site on GitHub Pages; all processing in the browser.

## Decisions

| Topic | Decision |
|---|---|
| Hosting | Dedicated repo, GitHub Pages, deployed by GitHub Actions |
| Output | SVG in mm with two layers: `pockets` and `boundary` |
| Camera | Handheld phone, roughly overhead: perspective corrected, lens distortion not |
| Offsets | User clearance only; kerf handled in CAM |
| Pockets | One closed outer outline per tool (holes ignored) |
| Extras in v1 | Smoothing slider, manual point editing |
| Stack | TypeScript, Vite, `d3-contour`, `clipper-lib`; no OpenCV |

## Pipeline

1. **Load:** decode with EXIF orientation, downscale to 3000 px long side, convert to gray.
2. **Calibrate:** user taps 4 corners of a grid rectangle and enters its size in squares. Corners are sorted TL, TR, BR, BL; a homography maps photo pixels to mm with the first corner as origin. A projected grid overlay lets the user check it.
3. **Warp:** resample the photo to a top-down image at 4 px/mm (capped at 4000 px), covering the whole photo clamped to a sane range around the rectangle. Off-photo pixels are white.
4. **Detect:** Otsu threshold (or manual), then morphological opening with a square of radius `gridRemovalMm` to strip grid lines. Opening uses summed-area tables, so it's O(n) at any radius.
5. **Trace:** `d3-contour` at 0.5 on the binary mask; keep outer rings, drop blobs touching the image edge (unlit surround) and blobs under the minimum area.
6. **Pocket:** grow by clearance + smoothing, shrink by smoothing (a morphological closing), then simplify at 0.05 mm. Closing only adds area, so the pocket never cuts into the clearance zone.
7. **Edit:** select, drag, insert, delete points; delete or reset tools. Edited pockets are not regenerated by clearance/smoothing changes; detection settings lock while edits exist.
8. **Export:** union all pockets (overlaps merge), add the boundary rectangle, translate so the page starts at 0,0.

## Testing

- Unit tests for homography, corner ordering, polygon helpers, pockets, SVG and editing helpers.
- End-to-end test renders a synthetic tilted photo (grid, a bar and a disc with known sizes), runs the full pipeline and checks sizes within 0.5 mm.

## Known limits

- No lens-distortion correction.
- A grid line running exactly along a tool edge can add up to its own width to that edge (the error makes the pocket bigger, never smaller).
- Through-cut single outlines only; no stepped depths, finger pulls or labels in v1.
